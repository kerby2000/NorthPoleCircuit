# IP5209 Scope Evidence

This folder is for local oscilloscope screenshots and waveform CSV files generated by:

```powershell
python Firmware\tools\scope\ip5209_lx_capture.py --mode idle
python Firmware\tools\scope\ip5209_lx_capture.py --mode wake-single
```

Generated `.csv`, `.png`, `.jpg`, and `.bmp` files are ignored by Git. Commit selected evidence only if it is small and directly supports a hardware decision.
