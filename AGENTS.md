# Codex Instructions For This Repository

## General Rule

When implementing a feature, do not only add new files. Also remove or update old code, stale docs, duplicate scaffolds, and obsolete paths.

Every task must end with a cleanup pass.

## Required Final Checklist

Before reporting completion, always run:

```powershell
python -B -m unittest Firmware.host_tests.test_firmware_logic
powershell -ExecutionPolicy Bypass -File Firmware\tools\build_matrix.ps1
git diff --check
git status --short
python Firmware\tools\repo_hygiene_check.py
```

Also check tracked files for generated artifacts:

```powershell
git ls-files | Select-String "__pycache__|\.pyc$|\.pyo$|\.pyd$|Firmware/src|Firmware/include|/build/|\.elf$|\.hex$|\.bin$|\.map$|\.log$|\.kicad_prl$|\.history|backups|PCB/production/.*\.(zip|xls|xlsx|csv|ipc)$"
```

## Stale-Code Cleanup Requirement

For every feature:

- List all files added.
- List all files modified.
- List all files deleted.
- Search for references to any removed files, old paths, old symbols, or obsolete APIs.
- Update documentation and tests together with code.
- Do not leave duplicate scaffold files unless they are explicitly documented.
- Do not commit generated build outputs, Python caches, IDE workspace state, or binary firmware artifacts.

## Firmware Source Of Truth

The active CH592 firmware source tree is:

```text
Firmware/northpole_ch592_bringup/APP/northpole/
Firmware/northpole_ch592_bringup/APP/include/
Firmware/northpole_ch592_bringup/Profile/
```

Do not recreate obsolete top-level firmware source folders:

```text
Firmware/src/
Firmware/include/
```

## Generated Pin Notes

`board_pins_autogen_notes.h` is generated by:

```text
Firmware/tools/extract_kicad_pinmap.py
```

Do not edit it manually. Regenerate it after schematic or PCB changes.

## Hardware Validation Status

Until real hardware is tested, keep these marked as unvalidated:

- USB CDC enumeration
- WS2812 timing
- WT2003 UART/audio behavior
- IP5209 I2C/register behavior
- Touch thresholds
- Motor movement and thermal limits
